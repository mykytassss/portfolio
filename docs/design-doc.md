# Дизайн-док: персональное портфолио

## 1. Цель
Одностраничный сайт-визитка, который за 30 секунд отвечает на вопросы: кто ты, что умеешь, что уже сделал и как с тобой связаться. Сайт должен легко обновляться без знания кода — правкой одного файла с контентом.

## 2. Аудитория
- Рекрутеры и наниматели — быстро оценить навыки и опыт.
- Потенциальные заказчики — посмотреть проекты и написать.
- Коллеги по разработке — перейти на GitHub и в репозитории.

## 3. Структура страницы
1. **Hero** — имя, роль (например, «Frontend-разработчик»), одна фраза о себе, кнопки «Проекты» и «Связаться».
2. **Обо мне** — 2–3 абзаца, фото/аватар (по умолчанию аватар с GitHub).
3. **Навыки** — сгруппированные теги: языки, фреймворки, инструменты.
4. **Проекты** — карточки: название, описание, стек, ссылки на демо и GitHub, превью-картинка.
5. **Опыт** — таймлайн: место, роль, период, ключевые результаты.
6. **Контакты** — e-mail, GitHub, Telegram, LinkedIn.
7. **Футер** — год, ссылка на исходники сайта.

## 4. Визуальный стиль
- Минимализм, много воздуха, один акцентный цвет.
- Светлая и тёмная тема (по системной настройке + переключатель).
- Типографика: системный шрифт или Inter; крупные заголовки.
- Адаптивность: mobile-first, корректно от 360 px до 1440 px+.
- Лёгкие анимации появления секций, с учётом `prefers-reduced-motion`.

## 5. Контент
Весь текст и данные — в одном файле `src/data/profile.ts` (имя, роль, «обо мне», навыки, проекты, опыт, контакты). Чтобы обновить сайт, достаточно отредактировать этот файл. В первой версии — заглушки, которые ты заменишь своими данными.

## 6. Технологии
| Решение | Выбор | Почему |
|---|---|---|
| Фреймворк | Astro | Статический HTML, почти ноль JS, быстрая загрузка |
| Стили | Обычный CSS с переменными | Без лишних зависимостей, просто менять тему |
| Язык | TypeScript | Типизация контента, меньше ошибок при правках |
| Хостинг | GitHub Pages | Бесплатно, деплой из репозитория |
| CI/CD | GitHub Actions | Автодеплой при пуше в `main` |

## 7. Нефункциональные требования
- Lighthouse ≥ 95 по производительности, доступности, SEO.
- Семантическая разметка, alt у картинок, навигация с клавиатуры.
- Meta-теги и Open Graph для красивого превью ссылки в соцсетях/мессенджерах.

## 8. Этапы
1. **v0.1 (сейчас)** — каркас на Astro, все секции с заглушками, тёмная тема, адаптивность, деплой на GitHub Pages.
2. **v0.2** — твой реальный контент, фото, превью проектов.
3. **v0.3** — по желанию: английская версия, блог/заметки, форма обратной связи.

## 9. Открытые вопросы
- Имя и роль, которые показывать на сайте.
- Какие проекты включить (3–6 лучших).
- Какие контакты публиковать.
- Нужна ли английская версия сразу.
- Свой домен или адрес `mykytassss.github.io/portfolio`.
